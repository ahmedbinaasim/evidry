# Is the name "provr" free to use?

Research for [issue #4](https://github.com/ahmedbinaasim/provr/issues/4). All checks were made on **2026-11-27**.
The project's own repository, `github.com/ahmedbinaasim/provr`, is ignored. Nothing was registered, reserved or signed up for.
This is a name search, not legal advice or a trademark clearance.

## Conclusion

**The package names are open, but the name is not clear. Treat the conflicts as serious.**

1. **PROVAR** is one letter away. Provar Limited sells software testing tools and holds live PROVAR registrations in the US, EU and UK covering testing software.
2. **[divait/provr](https://github.com/divait/provr)** is a developer command-line tool, also called `provr`, that runs tests against preview environments. It released v0.1.0 on 2026-11-21.
3. **provr.com** is in use by a business selling AI services under the name "Provr".
4. The **GitHub account `provr`** is already taken.

No live trademark for the exact word PROVR was found in the searches below.

## Existing products, projects and companies

### Direct conflicts

- **divait/provr** ([repository](https://github.com/divait/provr)). Go, Apache-2.0, created 2026-11-21, pre-alpha. Its README describes isolated preview environments for coding agents: it provides `provr` commands and `provr mcp`, runs tests against the stack, and reads `provr.yaml`. This overlaps on command name, config file name (the map in [issue #1](https://github.com/ahmedbinaasim/provr/issues/1) mentions `provr.yaml`), audience and purpose. It is fetchable through the [Go module proxy](https://proxy.golang.org/github.com/divait/provr/@latest). It has 0 stars.
- **Provar** ([provar.com](https://provar.com/)), Provar Limited. Companies House lists a PROVAR LIMITED, [08999736](https://find-and-update.company-information.service.gov.uk/company/08999736). Software test automation, mainly for Salesforce, with CI/CD integration. It also publishes a command-line plugin, [`@provartesting/provardx-cli`](https://www.npmjs.com/package/@provartesting/provardx-cli). "provr" reads as "Provar" with a vowel dropped.

### Same name, other fields

- **provr.com** ([site](https://provr.com/)): offers custom RAG systems, AI agents and digital twin integration; footer reads "© 2025 provr.com". The page title reads "prorvr". The legal entity and location are not stated.

Other exact names include R packages [ProvTools/provR](https://github.com/ProvTools/provR) and [GeoinformationSystems/provr](https://github.com/GeoinformationSystems/provr) (data provenance), [tristynb95/Provr](https://github.com/tristynb95/Provr), and [provrofficial/provr](https://github.com/provrofficial/provr).

The US PROVAR registration names, in class 9, downloadable software for "creating, maintaining, and executing automated tests for desktop, web and mobile software applications", and in class 42, testing and quality control of computer software. That is the same field as this project. Whether "provr" would be held confusingly similar is a legal judgment that this research does not make; the closeness of both the word and the goods makes the risk real.

## Alternatives checked

None of these is legally cleared. For each of the three, on 2026-11-27:

- no record on PyPI, npm, NuGet, crates.io, the official Homebrew taps, RubyGems, Docker Hub (user and organisation) or GitHub accounts;
- no GitHub repository with the name in a repository search;
- no VS Code Marketplace publisher page and no Open VSX namespace (extensions of that name were not searched);
- no result in USPTO Trademark Search for the exact word.

| Name | Domains (RDAP) | Notes |
| --- | --- | --- |
| **mutaproof** | `.com` and `.dev` not registered | Furthest from PROVAR and PROVER, so the first choice on conflicts. A web search found no product of this name. It suggests mutation testing, so use it only if planted-bug checking is central to the tool |
| **provsmith** | `.com` and `.dev` not registered | Closer to the current name. A web search found no product of this name. Still begins "prov", like Provar |
| **provewright** | `.com` **registered**, `.dev` not registered | A web search found no product of this name. The "-wright" ending may evoke Microsoft's Playwright testing tool |

**Not verified** for all three: EU and UK trademarks. TMview showed "No rows found" for them, but the site then started returning an error page, so those empty results could not be confirmed and are not relied on. Phonetic and near-spelling trademark searches were not done.

Rejected in screening because a name is already taken: `provekit` (PyPI, npm), `proofrun` (PyPI, npm, GitHub), `proofwright` (PyPI, GitHub). `assayr` has no registry record, but `assayr.com` is registered and an R package called assayr exists.

## Before relying on a name

- Check the EUIPO and UK IPO registers directly, including similar spellings.
- If keeping "provr", get a trademark professional's view on PROVAR first.
